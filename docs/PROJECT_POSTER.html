1. Problem & Motivation

University students face severe cognitive overload from unstructured lecture slides, textbooks, and syllabi.

Generic conversational chatbots suffer from unbounded hallucinations, lack structured active recall, and provide sterile interfaces that induce cognitive fatigue.

The Goal: Engineer a dual-engine architecture combining high-tempo active retrieval with strict source-grounded research (zero hallucinations).
🧠

2. Theoretical Foundations

  • The Testing Effect: Empirical research shows active retrieval practice significantly outperforms passive reading in long-term memory consolidation.
  • Source Grounding: Restricting the generative boundary of LLMs strictly to user-provided lecture notes to eliminate factual errors.
  • Affective Computing: Dynamic sensory atmospheres (Warrior Adrenaline Mode, Cozy Lo-Fi Lounge) modulate dopamine and sustain study endurance.
⚙️

4. Dual-Engine Architecture

A 4-tier cloud topology seamlessly uniting the Warrior Study Vault with the Google NotebookLM Studio:

[ CLIENT TIER: Next.js 15 + React 19 + Web Audio Synth ] │ ┌───────────────┴───────────────┐ ▼ ▼ [ STUDY VAULT ] [ NOTEBOOKLM STUDIO ] /api/generate /api/notebook/generate │ │ └───────────────┬───────────────┘ ▼ [ RESILIENT MULTI-MODEL FALLBACK LOOP ] Gemini-3-Preview ──► Gemini-3.5 ──► Gemini-2.5 │ ▼ [ STRICT ZOD VALIDATION & SCHEMA NORMALIZATION ] │ ▼ [ CLOUD DATA TIER: Firebase Auth + Admin Firestore ]

Multi-Model Fallback: If an endpoint returns 503 or 429 during load spikes, the handler automatically falls over in milliseconds without client failure.

🔄

5. Key Architectural Workflows

  • Zero-Hallucination Extraction: Source prompts wrap raw lecture notes inside strict token boundaries; Zod validates 100% conforming JSON.
  • Privileged Token Verification: Client Bearer JWTs verified server-side via Firebase Admin SDK to ensure total user data isolation.
  • Native Audio Synthesis: Synthesizes pink/brown noise and binaural frequencies via browser Web Audio API with zero audio file streaming overhead.
✨

6. Functional Modules

  • 3-Panel NotebookLM Studio: Synchronized layout displaying verbatim source excerpt, grounded FAQs, key concepts, and study tools.
  • 3D Perspective Flashcards: Active-recall tactile flip cards with keyboard shortcut controls (Space / Arrow keys).
  • Diagnostic Quiz Engine: 5-question multi-choice tests with immediate visual feedback and educational explanations.
  • Atmosphere Theming: Adrenaline Warrior, Cozy Lo-Fi Lounge, and Straight Nerd Blueprint modes.
